# 🔌 智慧能源監控系統 (Smart Energy Monitoring System)

本系統是一個基於 **Python Flask** 與 **SQLite** 的物聯網 (IoT) 能源數據監控儀表板。專案內包含了一個模擬器 (`simulator.py`)，可以模擬多個智慧型設備發送即時用電量至後端，並透過網頁儀表板動態顯示數據。

---

## 💻 系統環境需求
- **Python 3.6 或以上版本** (請確認安裝時有勾選 `Add Python to PATH` 以便在命令列使用)。

---

## 🚀 快速啟動說明

### 🔹 方法一：Windows 使用者 (最簡單)
我們已在專案目錄下提供 `雙擊啟動.bat` 檔案。
1. 直接**按兩下 (雙擊) 執行** `雙擊啟動.bat`。
2. 系統會自動完成：
   - 檢查 Python 環境並安裝必要套件 (`Flask`, `requests`)。
   - 在新視窗啟動 Flask 後端。
   - 自動開啟瀏覽器並連結至 `http://127.0.0.1:5000`。
   - 在原視窗開始執行 `simulator.py`（模擬設備發送電力數據）。
3. **欲結束程式**：直接關閉那兩個命令列視窗即可。

---

### 🔹 方法二：命令列手動啟動 (Windows / macOS 均適用)
此專案需要同時執行兩個 Python 程式。請分開打開兩個終端機 (Terminal) 視窗：

#### 🔸 步驟 1：啟動 Flask 後端
在第一個終端機執行：
```bash
# 1. 切換至專案目錄
cd IoT-001

# 2. 安裝套件
pip install -r requirements.txt

# 3. 啟動後端
python app.py
```
👉 開啟瀏覽器並訪問 `http://127.0.0.1:5000`。

#### 🔸 步驟 2：啟動數據模擬器
在第二個終端機執行：
```bash
# 1. 切換至專案目錄
cd IoT-001

# 2. 啟動模擬器
python simulator.py
```
模擬器啟動後，網頁儀表板上就會開始動態繪製各個設備的即時用電量折線圖。

## ⚠️ 高能耗警示閾值
為防止設備過載，系統針對不同設備設置了警示閾值，當模擬用電量超過時會觸發警示 UI 視覺效果：
* **Device-A (Chiller 冰水主機)**: `180.0 kW`
* **Device-B (Air Compressor 空壓機)**: `110.0 kW`
* **Device-C (HVAC 空調箱)**: `55.0 kW`

**警示表現形式**：
1. **即時圖表**：Chart.js 圖表中的超標點會以紅色圓點高亮顯示，懸停 Tooltip 會加上 `⚠️ (超標)` 註記。
2. **即時日誌**：最新能耗數據表格中，超標項目的整行背景會以淡紅色標記，並附加紅色 `⚠️ 高耗電` 徽章。

## 🛠️ 設備維護與履歷系統
整合了線上故障申報、工作流看板與維護歷史：
1. **故障申報**：登入後即可在報修頁面填寫設備名稱與狀況描述。
2. **即時維護看板**：
   - 狀態分為 **待處理** (黃色) ➔ **維修中** (藍色) ➔ **已結案** (綠色，歸檔至歷史履歷)。
   - 管理員可於看板上一鍵接單 (`維修中`) 或結案 (`已結案`)，接單人與修復時間會自動寫入資料庫。
3. **設備歷史維護履歷**：已完成的維護項目將歸檔於此，形成透明的維護紀錄，便於長期追蹤。
